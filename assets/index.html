The studio

Frog Creative is a team from Australia and Indonesia, founded on 28 October 2026, that works on Minecraft servers for both Java Edition and Bedrock Edition.

We are a studio of six, so the people who write the server software are the same people who run the server. When something breaks for a Bedrock player at night, it is our problem to fix.

Technology

Software we maintain ourselves.

Lucyper

Our private fork of PaperMC, modified for the needs of our own servers.

Private software

Waterfall

A private proxy for Bedrock Edition, built on a fork of GeyserMC. Bedrock and Java players can join the same server at the same time. Our work centres on bug fixes and Bedrock stability.

Private software

GoLeaf

Server software for Bedrock Edition, written in Go. It is light, fast and supports multiple protocols, and it was built from the start for minigames rather than vanilla Minecraft.
